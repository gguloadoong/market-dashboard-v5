
**완화책 (DJ 멘트 신뢰성)**:
- 모든 숫자는 원본 데이터 링크로 검증 가능
- "추측"(왜 오르는지 인과)과 "사실"(가격·수급·뉴스 헤드라인) 시각적 분리
- 초기엔 결정론적 템플릿만, LLM 자유 작문은 신뢰 쌓인 후

## 결합 가능성 (참고만)

- **DJ + 트리아지**: DJ 멘트가 "지금 RED 카드" 알려줌 (가장 자연스러운 결합)
- **매거진 + 미니맵**: 표지 1면 + 하단에 미니맵
- ⚠️ 결합은 직전 "D+A 결합" 함정 재현 위험 — Strategy/CPO/FE 모두 D+A 결합 기각 사례 참조

## 결정 기준 (다음 사이클)

다음 세션에서 디자인 사이클 재개 시:

1. **사용자 인터뷰 5명 (Strategy 권고)** — 시안 보여주고 "5초 안에 이 앱은 X다" 직접 검증
2. **prototype 1개 빨리 (Gemini 권고)** — 가장 가벼운 시안(매거진 3~4주)으로 만들고 직접 써보기
3. **트래픽 5% A/B (CPO 권고)** — 코드는 통째로 교체, 사용자 노출만 단계적 (5% → 25% → 50% → 100%)

## 영감 라운드 자체 메타 비판

- 4개 모두 ASCII 목업 + 가설 + 위험까지 갖췄으나 **정적 HTML은 아직 없음**
- 영감 카드는 디자이너가 시각 정교화하기 전 단계
- "D+A 결합" 함정처럼 4개 중 둘 합치는 본능 경계
